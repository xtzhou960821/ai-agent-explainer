# Harness 与开发框架 FAQ 设计

## 目标

在现有“常见问题”手风琴区域新增 6 条面向初学者的问答，帮助读者把 Harness、开发框架、单/多 Agent 和生产运行保障关联到实际选型决策。

## 内容范围

新增问题依次覆盖：

1. Harness 与开发框架的区别。
2. 是否必须使用开发框架。
3. 使用框架内置 Harness 与自建 Harness 的边界。
4. LangGraph、Google ADK、OpenAI Agents SDK 与 CrewAI 的选型思路。
5. 多 Agent 是否优于单 Agent。
6. 生产环境中 Harness 应优先补齐的能力。

每个答案保持一段、面向非专业读者，避免把某一框架表述为唯一正确选择；强调先从简单、可观测、可验证的方案开始。

## 页面与交互

- 仅编辑 `index.html` 的现有 FAQ 区域，在原有 4 条问题之后追加 6 个同构的 `.faq-item`。
- 复用已有 CSS、展开动画、`aria-expanded` 属性与点击脚本，不引入依赖或新增行为。
- FAQ 总数从 4 条变为 10 条，页面版式与移动端横向一致。

## 验证

1. 运行 `git diff --check`，确保 HTML 变更不存在空白错误。
2. 检查新增条目均使用现有 FAQ 的按钮、答案容器和无障碍属性结构。
3. 在本地静态预览中确认每条问答可独立展开与收起，且原有 FAQ 仍可用。
